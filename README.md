# AutoChat

A React chat app where **AutoBot** replies automatically.

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## What it does

- Send a message; AutoBot types briefly, then replies on its own
- Keyword replies for greetings, help, jokes, time/date, and more
- Enter to send, Shift+Enter for a new line
